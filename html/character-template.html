01

概要・立ち回り方針

OVERVIEW

飛び道具（波動拳）、無敵対空（昇龍拳）、突進技（竜巻旋風脚）と、格ゲーの基本となる技がそろったキャラクターです。技の性能が素直で、基礎を学ぶのに最適です。

立ち回りの方針

  • 中距離：波動拳で相手の動きを制限し、飛んできたら昇龍拳で落とす
  • 差し合い：屈中Kに波動拳を入れ込んで、触れたらダメージを取る
  • 攻め：電刃錬気で必殺技を強化し、ラッシュや鎖骨割り（中段）で崩す

強み

  • 無敵対空があり、ジャンプに強い
  • 飛び道具で距離を管理しやすい
  • コンボがシンプルで安定する

弱み

  • 突出した崩し性能はない
  • 電刃錬気を活かすには知識が必要

03

コンボ

COMBOSSAMPLE

分類ごとにタブで切り替えられます。コマンドは「›」の順に入力します。

このテンプレートのコンボは表示確認用のサンプルです。実際に掲載する前に、トレーニングモードで成立とダメージを確認してください。

まず覚えたい、実戦で一番使うコンボ。

B-01

屈中K → 波動拳

↓中K›↓↘→ + P
ダメージ 要計測Dゲージ 0本SAゲージ 0本難易度

差し合いの基本。屈中Kが当たっても当たらなくても波動拳まで入れ込む。

B-02

強P → 鳩尾砕き → 強上段足刀蹴り

強P›→ + 強P›↓↘→ + 強K
ダメージ 要計測Dゲージ 0本SAゲージ 0本難易度

確定反撃の基本形。相手を画面端方向へ大きく吹き飛ばす。

B-03

屈弱P → 屈弱P → 弱竜巻旋風脚

↓弱P›↓弱P›↓↙← + 弱K
ダメージ 要計測Dゲージ 0本SAゲージ 0本難易度

小技からのヒット確認用。

画面端へ相手を運ぶことを優先したコンボ。

C-01

屈中P → キャンセルラッシュ → 強P → 鳩尾砕き → 強上段足刀蹴り

↓中P›→→›強P›→ + 強P›↓↘→ + 強K
ダメージ 要計測Dゲージ 3本SAゲージ 0本難易度

ドライブゲージを使って運びとダメージを両立。

C-02

強P → 鳩尾砕き → 強竜巻旋風脚

強P›→ + 強P›↓↙← + 強K
ダメージ 要計測Dゲージ 0本SAゲージ 0本難易度

ゲージを使わずに運ぶ。

画面端でダメージを最大化するコンボ。

E-01

強P → 鳩尾砕き → 強竜巻旋風脚 → 強昇龍拳

強P›→ + 強P›↓↙← + 強K›→ ↓↘ + 強P
ダメージ 要計測Dゲージ 0本SAゲージ 0本難易度

画面端限定。竜巻後の追撃で昇龍拳を当てる。

ドライブインパクトがパニッシュカウンターした時のコンボ。

P-01

インパクト（パニカン） → 前ステ → 強P → 鳩尾砕き → 強上段足刀蹴り

強P + 強K（PC）›→→›強P›→ + 強P›↓↘→ + 強K
ダメージ 要計測Dゲージ 1本SAゲージ 0本難易度

崩れ落ちた相手に前ステから拾う。

P-02

画面端インパクト（壁やられ） → 強P → 鳩尾砕き → 強竜巻旋風脚 → 強昇龍拳

強P + 強K›強P›→ + 強P›↓↙← + 強K›→ ↓↘ + 強P
ダメージ 要計測Dゲージ 1本SAゲージ 0本難易度

画面端でインパクトをガードさせた時も同じルートで拾える。

SAを使って倒し切るためのコンボ。

L-01

強P → 鳩尾砕き → SA3（真・昇龍拳）

強P›→ + 強P›↓↘→↓↘→ + K
ダメージ 要計測Dゲージ 0本SAゲージ 3本難易度

体力25%以下ならCAに変化してダメージアップ。

L-02

屈中K → SA1（真空波動拳）

↓中K›↓↘→↓↘→ + P
ダメージ 要計測Dゲージ 0本SAゲージ 1本難易度

差し合いのついでに倒し切る時に。

相手をスタン（気絶）させた時の最大ダメージ。

S-01

スタン → 前ジャンプ強K → 強P → 鳩尾砕き → 強上段足刀蹴り

↗ 強K›強P›→ + 強P›↓↘→ + 強K
ダメージ 要計測Dゲージ 0本SAゲージ 0本難易度

ゲージなしの基本形。

S-02

スタン → 前ジャンプ強K → 強P → 鳩尾砕き → SA3

↗ 強K›強P›→ + 強P›↓↘→↓↘→ + K
ダメージ 要計測Dゲージ 0本SAゲージ 3本難易度

SAゲージがある時の最大ダメージ。

セットプレイ・起き攻めパターン

コンボの締め（起点）ごとに、その後の行動・有利フレーム・重ねる技をまとめます。有利Fは計測して記入してください。
