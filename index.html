01 GAME RULES

ゲームルール

体力バー、ドライブゲージ、SAゲージ、パニッシュカウンターなど試合の基本を解説。

体力バーゲージパニカン → 02 GAME MODES

各モードの遊び方

アーケード、ランクマッチ、コンボトライアル、トレーニングなどの使い分け。

アーケードランクマトライアル → 03 RANK SYSTEM

ランクについて

ルーキーからマスターまでの段位、LPとMR（マスターレート）の仕組み。

ルーキーマスターMR → 04 CONTROLS

基本操作方法

パッド／アケコン／レバーレス、クラシックとモダンの違いと選び方。

デバイスクラシックモダン → 05 CHARACTER SELECT

キャラクター選択画面

キャラクターごとのコンボレシピとセットプレイ（有利フレーム・重ね技）をまとめたデータベース。

コンボセットプレイ有利F → 06 HISTORY

ストリートファイターの歴史

初代から6まで、シリーズの歩みとシステムの変遷を年表で振り返る。

シリーズ年表システム → 07 DIARY

投稿主の日記

プレイ日記、アップデートの感想、サイトの更新情報をブログ形式で掲載しています。

プレイ日記アップデート更新情報 →

HOW TO USE

サイトの使い方

  1. 1
    トップのカードから学ぶテーマを選ぶ

    初心者は「01 ゲームルール」→「04 基本操作方法」の順がおすすめ。

  2. 2
    右上の MENU からいつでも移動

    どのページからでも各コンテンツへジャンプできます。

  3. 3
    キャラ対策は「05 キャラクター選択」へ

    コンボは「技名＋矢印コマンド」、セットプレイは有利Fと重ね技で掲載。
